# Instructions
Running data_collection.py will produce the raw data which will be saved as 'round_2_decisions.csv' and 'pistols_and_thrifties.csv'. Running data_processing.py will process the data and the processed data will be saved as 'r2_cleaned.csv' and 'pat_cleaned.csv'. However, both of these modules take a very long time to run until completion.
Instead, the processed data (and raw data) can be downloaded directly from https://drive.google.com/drive/folders/1MxjjALxFO6f0veBe4OiE-MZGwbqI0bhb.

Once the processed data has been downloaded, the correct libraries need to be installed. Open up a terminal and type in the following commands:
- pip install vlrdevapi
- pip install pandas
- pip install matplotlib
- pip install seaborn

After the processed data and the libraries have been installed, both data_analysis.py and project_tests.py are able to be ran and the results from the report will be recreated.
